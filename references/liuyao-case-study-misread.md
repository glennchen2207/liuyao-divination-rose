# Case Study: Coin Misread Changes Entire Reading

**Date**: 2026-05-12
**Context**: Career divination — headhunter offer from former VP

## The Misread

User provided: 反反正，**反正反**，反反反，正反反，反正正，正正正

Agent read:    反反正，**正反正**，反反反，正反反，反正正，正正正

The 2nd line: "反正反" (1正2反 = 少陰 --) was misread as "正反正" (2正1反 = 少陽 —).

## Impact Comparison

| Aspect | Misread (水澤節) | Correct (水雷屯) |
|--------|-----------------|-----------------|
| 本卦 | 水澤節 ☵☱ | 水雷屯 ☵☳ |
| 卦義 | 節制適度，中道而行 | 勿用有攸往，宜守不宜進 |
| Advice direction | **Can proceed with restraint** ✅ | **Don't go** ❌ |
| 二爻 | 少陽 — 丁卯 子孫 | 少陰 -- 庚寅 子孫(世) |
| 世爻 | 初爻 丁巳 妻財 | 二爻 庚寅 子孫 |
| 動爻化關係 | 官鬼化回頭生 ✅ | 官鬼化回頭剋 ❌ |
| Final advice | 節制可進 | 現階段不宜跳槽 |

**Conclusion**: Completely opposite life advice. This is why coin verification is mandatory before proceeding with interpretation.

- **世爻**: 二爻庚寅木子孫持世休 — 心有旁騖，對現狀不滿
- **應爻**: 五爻戊辰土官鬼玄武相 — 對方有實力

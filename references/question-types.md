## 事業工作

### 用神

**官鬼爻**為主用神（工作、職位、上司）

### 斷卦要點

| 判斷項 | 吉象 | 凶象 |
|:------:|:-----|:-----|
| **官鬼旺衰** | 官鬼旺相，有生氣 | 官鬼休囚，無生氣 |
| **官鬼空破** | 不空不破 | 空亡或月破 |
| **官鬼動變** | 動而化進神 | 動而化退神、化回頭剋 |
| **世應關係** | 應生世，官鬼生世 | 應剋世，官鬼剋世 |
| **原神** | 財爻旺相生官 | 財爻休囚不生官 |

### 特殊情況

- **求職**：官鬼為職位，妻財為薪水。官鬼旺相有氣，求職可成。
- **升遷**：官鬼旺相且得生扶，升遷有望。
- **創業**：官鬼為阻力，宜弱不宜強。子孫爻旺相為吉。
- **工作變動**：世爻或官鬼動，主有變動。

### 詳細解讀

**官鬼旺相**：工作順利，有升遷機會，上司賞識。

**官鬼休囚**：工作不順，無發展，上司不滿。

**官鬼空亡**：職位不穩，可能失業，或無心工作。

**官鬼月破**：工作有變，小心被解雇。

**官鬼發動**：
- 化進神：升遷、加薪、更好職位
- 化退神：降職、離職、不如意
- 化回頭剋：工作受阻，有人刁難
- 化回頭生：工作順利，得貴人相助

**世爻持官鬼**：自己有職位，但壓力大。

**應爻持官鬼**：對方有權力，對我有影響。

**官鬼生世**：上司賞識，工作順利。

**官鬼剋世**：上司刁難，工作壓力大。

## 財運投資

### 用神

**妻財爻**為主用神。

### 斷卦要點

| 判斷項 | 吉象 | 凶象 |
|:------:|:-----|:-----|
| **妻財旺衰** | 妻財旺相 | 妻財休囚 |
| **妻財空破** | 不空不破 | 空亡或月破 |
| **妻財動變** | 動而化進神 | 動而化退神 |
| **財源** | 子孫爻旺相生財 | 子孫爻休囚 |
| **劫財** | 兄弟爻休囚 | 兄弟爻旺相劫財 |

### 特殊情況

- **正財**：妻財旺相不動，穩定收入。
- **偏財**：妻財發動，意外之財。
- **投資**：妻財旺相，子孫生財，可投資。
- **借貸**：妻財旺相可借出，兄弟旺相不宜借。

### 詳細解讀

**妻財旺相**：財運亨通，有進帳。

**妻財休囚**：財運不佳，收入減少。

**妻財空亡**：錢財落空，投資失利，不宜借貸。

**妻財月破**：破財之象，需防盜賊。

**妻財發動**：
- 化進神：財運漸佳，收入增加
- 化退神：財運漸差，收入減少
- 化回頭剋：破財，投資失敗
- 化回頭生：進財，投資成功

**兄弟持世**：劫財，開銷大，不宜投資。

**兄弟發動**：劫財之象，需防破財。

**子孫生妻財**：有財源，投資可獲利。

**官鬼生妻財**：有貴人帶財。

## 感情婚姻

### 用神

- **男測感情**：妻財爻為用神（女方）
- **女測感情**：官鬼爻為用神（男方）
- **測婚姻**：妻財、官鬼皆參考

### 斷卦要點

| 判斷項 | 吉象 | 凶象 |
|:------:|:-----|:-----|
| **用神旺衰** | 用神旺相 | 用神休囚 |
| **用神空破** | 不空不破 | 空亡或月破 |
| **世應關係** | 世應相生相合 | 世應相剋相沖 |
| **用神持世** | 對方對我有意 | 自己單戀 |
| **原神** | 有原神生扶 | 無原神 |

### 特殊情況

- **單戀**：用神不持世，或應爻剋世。
- **第三者**：用神發動，或兄弟爻劫財。
- **復合**：用神旺相，世應相生。
- **求婚**：用神旺相，官鬼或妻財持世。
- **對方態度**：應爻旺衰看對方誠意。

### 詳細解讀

**用神旺相**：對方條件好，有誠意。

**用神休囚**：對方條件普通，或無誠意。

**用神空亡**：對方無意，或單戀無果。

**用神月破**：感情生變，或分手跡象。

**用神持世**：對方對我有意，或已經在一起。

**用神持應**：對方主動，我有回應。

**應生世**：對方對我很好，主動追求。

**世生應**：我主動追求，對方回應。

**世剋應**：我佔主導，對方順從。

**應剋世**：對方強勢，我處弱勢。

**世應相沖**：意見不合，爭吵多。

**兄弟劫財**：有第三者介入。

**子孫生財**：感情發展順利，有貴人相助。

**官鬼發動**：男測感情，有變動。

**妻財發動**：女測感情，有變動。

## 健康疾病

### 用神

- **官鬼爻**：疾病之源
- **子孫爻**：醫藥、醫生

### 斷卦要點

| 判斷項 | 吉象 | 凶象 |
|:------:|:-----|:-----|
| **官鬼旺衰** | 官鬼休囚 | 官鬼旺相 |
| **官鬼空破** | 官鬼空破（病輕） | 官鬼旺相不空 |
| **子孫旺衰** | 子孫旺相 | 子孫休囚 |
| **世爻旺衰** | 世爻旺相 | 世爻休囚 |

### 疾病部位判斷

| 官鬼位置 | 可能部位 |
|:--------:|:---------|
| 乾宮（金） | 頭、肺、骨骼 |
| 坤宮（土） | 腹、胃、脾 |
| 震宮（木） | 肝、膽、手足 |
| 巽宮（木） | 肝、膽、風疾 |
| 坎宮（水） | 腎、泌尿、耳 |
| 離宮（火） | 心、眼、血 |
| 艮宮（土） | 背、手、鼻 |
| 兌宮（金） | 口、肺、皮膚 |

### 詳細解讀

**官鬼旺相**：病情較重，難以痊癒。

**官鬼休囚**：病情較輕，可望康復。

**官鬼空亡**：病輕或無大病。

**官鬼月破**：病情有變化。

**子孫旺相**：有良醫良藥，可痊癒。

**子孫休囚**：醫藥無效，需換醫生。

**子孫發動**：病情有轉機。

**官鬼發動**：病情惡化或轉移。

## 考試學業

### 用神

**父母爻**為主用神（文書、成績、文憑）

### 斷卦要點

| 判斷項 | 吉象 | 凶象 |
|:------:|:-----|:-----|
| **父母旺衰** | 父母旺相 | 父母休囚 |
| **父母空破** | 不空不破 | 空亡或月破 |
| **官鬼** | 官鬼生父母 | 官鬼休囚 |
| **世爻** | 世爻旺相 | 世爻休囚 |

### 詳細解讀

**父母旺相**：考運佳，成績好。

**父母休囚**：考運差，成績不佳。

**父母空亡**：考試落榜，或無心學習。

**父母月破**：考試失常，發揮不好。

**官鬼生父母**：有貴人相助，考運好。

**世爻旺相**：自己狀態好，有信心。

**世爻休囚**：狀態不佳，需要努力。

## 官非訴訟

### 用神

**官鬼爻**為訴訟，**世爻**為自己，**應爻**為對方。

### 斷卦要點

| 判斷項 | 吉象（勝訴） | 凶象（敗訴） |
|:------:|:------------:|:------------:|
| **世應強弱** | 世強應弱 | 世弱應強 |
| **世應關係** | 世剋應 | 應剋世 |
| **官鬼** | 官鬼生世 | 官鬼剋世 |
| **判決** | 官鬼空亡 | 官鬼旺相 |

### 詳細解讀

**世強應弱**：我方有利，可勝訴。

**應強世弱**：對方有利，恐敗訴。

**世剋應**：我方佔上風。

**應剋世**：對方佔上風。

**官鬼生世**：法官偏向我方。

**官鬼剋世**：法官偏向對方。

**官鬼空亡**：訴訟可和解。

## 綜合斷卦原則

### 斷卦步驟

1. **取用神**：根據問題確定用神
2. **看旺衰**：判斷用神旺相休囚死
3. **看空破**：是否空亡或月破
4. **看動變**：動爻的變化
5. **看原神**：生用神者是否存在
6. **看忌神**：剋用神者是否猖獗
7. **看世應**：世應關係
8. **看卦象**：卦名、卦義

### 吉凶判斷核心

**用神**是核心：
- 用神旺相 + 原神有力 = 大吉
- 用神旺相 + 無原神 = 中吉
- 用神休囚 + 有生扶 = 小吉
- 用神休囚 + 無生扶 = 平
- 用神空破 = 凶
- 用神死絕 = 大凶

### 動爻重要性

動爻是變化的關鍵：
- 動而化進神：事情發展順利
- 動而化退神：事情退步
- 動而化回頭剋：受阻礙
- 動而化回頭生：得助力

### 時間判斷

應驗時間：
- 用神旺相：速應（日、月）
- 用神休囚：遲應（年）
- 動爻發動：近期應驗
- 靜爻旺相：待沖動時應驗
